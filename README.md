# \# Proyecto Colaborativo Git

# 

## \## Descripción

## 

### Este proyecto permite gestionar una lista de usuarios mediante un menú por consola.

## 

## \## Archivos principales

## 

### \- usuarios.py: contiene las funciones para agregar, listar y buscar usuarios.

### \- main.py: ejecuta el menú principal de la aplicación.

### \- tests/test\_analisis.py: incluye pruebas básicas de funcionamiento.

### \- README.md: documentación del proyecto.

### 

## \## Funcionalidades

## 

### \- Agregar usuarios.

### \- Listar usuarios registrados.

### \- Buscar usuarios por nombre.

### \- Mostrar menú principal.

##

## 

### Para ejecutar el programa:

### ```bash

### python main.py
